# Inner Glow
# 2D-платформер (название игры)

Игра написана на языке GDScript в среде Godot Engine в рамках учебной практики в Санкт-Петербургском Государственном Университете Аэрокосмического Приборостроения (ГУАП) студентками группы 4528 1 курса направления 09.03.02 (информационные системы и технологии в медиаиндустрии) – Коровкиной Елизаветой и Мелешкиной Вероникой.

## Суть игры

Нужно управлять персонажем, собирать сердечки и достигать портала. Для прохождения уровня необходимо собрать не менее 10 сердечек. Всего в игре 6 уровней: 3 простых (только сбор сердечек) и 3 сложных (помимо сердечек есть враги, которых можно убить, прыгнув на них сверху).

При сборе каждого сердечка на экране появляется текстовая фраза. Эти фразы постепенно раскрывают историю персонажа — его потерю памяти, внутренние сомнения и принятие себя.

## Управление

| Клавиша | Действие |
|---------|----------|
| A / D или стрелки влево/вправо | Движение |
| Пробел / Enter | Прыжок |
| Клавиши (настраиваются в Input Map) | Лазание по стенам |
| Esc | Выход в меню выбора уровня |
